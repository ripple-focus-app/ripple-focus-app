### Ripple (涟漪)

I make Ripple, a free app blocker and screen time app with no ads and no account. Each guide I write covers two readers: adults limiting their own phone and parents setting limits on a child's phone.

- Android v0.1.20 (Android 8.0 or later): schedules, a daily amount per app including 0 minutes, open limits, a break rule, quick focus, blocked websites, a usage calendar and strict mode with an unlock code someone else can keep.
- iPhone v0.1.5 (iOS 16 or later): blocking by schedule, stops apps being deleted, clock protection and an unlock code. No daily limits yet.
- No remote management and no parent app. Rules are set on the phone itself.
